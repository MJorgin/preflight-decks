# Critique Rubric

Score from **rendered screenshots**, never from source. Six dimensions,
0–10 each. Weight the average toward concept and hierarchy
(suggested: concept 0.25, hierarchy 0.2, craft 0.15, function 0.2,
originality 0.1, motion 0.1).

## 0. Concept (highest weight)

- 9–10: an idea grown from the content; the motif is irreplaceable
- 7–8: clear idea, motif relevant but reusable on a nearby topic
- 5–6: style without argument — pretty, says nothing in pictures
- 3–4: template reskin
- 1–2: no style even, decorative pile-up

**Veto: concept ≤ 5 caps the total at 6.0. Fix with a new idea sentence and
a reopened gate, not polish.**

Ask: Can you say the idea in one sentence? Does it pass the name-swap and
cover tests? Does the motif do its three jobs (open, recur, close)?

## 1. Visual hierarchy

- Title-to-body ratio, weight, and color must create 3–4 unmistakable levels.
- Squint test: the reading order is still obvious blurred.
- One focal point per slide; dense data slides still need a clear entry.
- Dense reading decks win through structure (grid, rules, tabs), not by
  shrinking type.

## 2. Craft

- 8pt-ish spacing system applied consistently; same component keeps the same
  metrics everywhere
- Edge alignment exact; optical alignment checked for punctuation and glyphs
- ≤2 type families; ≤3–4 purposeful colors; styles driven by variables
- Every chart/icon resolves at 720p; no orphan rules or dead space
- Numbers, units, dates, and capitalization follow one convention

## 3. Function

- Delete test: any element whose removal changes nothing gets removed
- Slide count respects the density mode; overflow is solved by splitting,
  never by shrinking text below the readable floor
- Speaker decks: a listener gets the point while watching the speaker
- Reading decks: the slide stands alone in async review
- CTA/conclusion is the strongest moment, not an afterthought

## 4. Originality

- No default palette clichés (purple-on-white gradients, dark neon dashboards
  without brand reason), no emoji-as-icon system, no generic 3D blobs
- Display typeface is a deliberate choice suited to the argument, not the
  model's usual fallback
- At least one "unexpected but inevitable" decision the audience remembers
- The wildcard's point of view survives into the final deck

## 5. Motion

- Entrances follow reading order with stagger; one orchestrated load beats
  constant micro-animation
- Transitions encode relation (continuity, contrast, time jump); no naked
  cuts and no competing transitions at one seam
- State holds truly still after settling — no tail drift
- Reduced-motion path exists and remains understandable
- Loop point of an animated deck is designed (end state ≈ open state or a
  deliberate resolution)

## Output format

```
## Deck critique — <name>
Total: X.X (bar 7.5, no dimension < 6; concept veto check: pass/fail)
- Concept X — one sentence
- Hierarchy X — one sentence
- Craft X — one sentence
- Function X — one sentence
- Originality X — one sentence
- Motion X — one sentence

Keep: [specific decisions worth preserving]
Fix:
1. [fatal/important/polish] current → why → exact change with values
Quick wins (if only 10 minutes): top 3
```

Re-score after fixes. A run that cannot reach the bar after two fix passes
has a concept or outline problem — reopen Stage 1 instead of polishing.
